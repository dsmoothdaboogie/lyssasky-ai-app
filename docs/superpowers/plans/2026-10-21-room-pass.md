# Room Pass Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Turn the $5 one-shot preview into a $5 Room Pass — first preview + up to 5 style/color restyles for 7 days, watermarked, with a free-chat + 10%-off perk code — and steer every pass state toward booking Marjorie.

**Architecture:** The pass and perk live as snapshotted fields on the existing `leads/{id}` doc, written atomically when payment is confirmed. A new owner-guarded `restyle` callable reserves a restyle inside a Firestore transaction, runs the shared generation core with an overridden style/colorMood, and refunds on failure. Watermarking is a `sharp` composite step inside `generateImage` (funnel only, not the test bench). An hourly scheduled function queues a one-time "pass ending" email. Client changes are concentrated in `ResultStep` (looks strip, pass status, restyle picker, Marjorie card) and `BookingStep` (perk + interest).

**Tech Stack:** React 19 + Vite + TS, Firebase (Firestore, Storage, Functions v2 incl. `firebase-functions/v2/scheduler`), `sharp` (new, functions only), Vitest, `@firebase/rules-unit-testing`, Playwright.

**Spec:** `docs/superpowers/specs/2026-10-21-room-pass-design.md`

## Global Constraints

- Pass defaults (AppConfig, admin-editable): `passRestyles: 5`, `passDays: 7`, `perkDiscountPct: 10`, `perkDays: 30`.
- Pass/perk values are **snapshotted onto the lead at payment**; later config/price changes never alter an existing pass.
- The **first preview does not count** toward `restylesTotal`; a pass yields up to `1 + restylesTotal` images.
- A restyle changes **only `styleSlug` + `colorMood`**; photo and other answers are reused.
- A **failed restyle never consumes a restyle** and never moves the lead to `failed` (only a failed *first* preview does).
- Restyles are allowed while `rated` or `booked` until `pass.expiresAt`; restyles never change lead status.
- Perk code format: `ROOM-` + 4 chars from `ABCDEFGHJKLMNPQRSTUVWXYZ23456789` (no O/0/I/1).
- Perk copy: free 15-min chat ("Marjorie will have your looks ready") **and** 10% off Virtual Styling (from $250) or Room Refresh (from $650).
- Lead writes stay callable-only; `firestore.rules` is not changed.
- All customer-facing HTML in emails goes through `escapeHtml`.
- Everything must run offline against the emulator (`demo-lyssasky`); mail is only written to the `mail` collection.

**Commands used throughout:**
- Root unit/component: `npx vitest run <path>`
- Functions integration (emulator): `firebase emulators:exec --project demo-lyssasky --only auth,firestore,storage 'cd functions && npx vitest run <path>'`
- Functions build: `npm --prefix functions run build`
- E2E: `npm run e2e`

**Deliberate deviation from spec §5 (approved in chat 2026-10-21):** the restyle wait is shown **inline on the result page** instead of navigating to `/wait`. After the first preview the lead is already `generated`, so `WaitScreen` (which redirects on `status === 'generated'`) would bounce back before the restyle finishes. `restyle` is awaited synchronously (as `regenerate` is today), so the page shows the wait animation until the callable resolves.

## Review Focus

1. **Double-tap / two tabs on Restyle** — exactly one generation runs, the second call gets "A look is already being generated", and only one restyle is consumed. (Task 5 concurrency test.)
2. **Restyle requested exactly at/after expiry or with the last restyle** — boundary: `now === expiresAt` is expired; `restylesUsed === restylesTotal` is exhausted; the UI shows the Marjorie screen, not a dead button. (Task 1 boundary tests, Task 10 exhausted-state test.)
3. **A stale `inFlight` marker after a crashed function** — a restyle stuck >3 minutes must not lock the customer out forever. (Task 5 stale-inFlight test.)
4. **Mock/tiny images through the watermark** — the 1×1 mock PNG must pass through untouched (no sharp error, no `watermarkFailed` flag) so the offline funnel keeps working. (Task 4 tiny-image test.)
5. **Emailed cross-device link after expiry** — still shows every look and the perk, read-only, no restyle controls. (Task 6 token test + Task 10 token-mode test.)

```ts
import type { AppConfig, Lead, LeadPass, LeadPerk, Look } from './types';

export const DAY_MS = 24 * 60 * 60 * 1000;
/** A restyle marker older than this is treated as abandoned (crashed function). */
export const IN_FLIGHT_STALE_MS = 3 * 60 * 1000;
/** No O/0/I/1 so codes read unambiguously over the phone or in an email. */
export const PERK_CODE_ALPHABET = 'ABCDEFGHJKLMNPQRSTUVWXYZ23456789';

export function restylesLeft(lead: Pick<Lead, 'pass'>): number {
  if (!lead.pass) return 0;
  return Math.max(0, lead.pass.restylesTotal - lead.pass.restylesUsed);
}

export function isPassExpired(lead: Pick<Lead, 'pass'>, now: number): boolean {
  if (!lead.pass) return true;
  return now >= lead.pass.expiresAt;
}

export function isRestyleInFlight(lead: Pick<Lead, 'pass'>, now: number): boolean {
  const started = lead.pass?.inFlight;
  return started !== undefined && now - started < IN_FLIGHT_STALE_MS;
}

export function canRestyle(lead: Pick<Lead, 'pass'>, now: number): boolean {
  return !isPassExpired(lead, now) && restylesLeft(lead) > 0;
}

export function isPerkValid(lead: Pick<Lead, 'perk'>, now: number): boolean {
  if (!lead.perk || lead.perk.redeemedAt !== undefined) return false;
  return now < lead.perk.validUntil;
}

export function generatePerkCode(rand: () => number = Math.random): string {
  let suffix = '';
  for (let i = 0; i < 4; i++) {
    suffix += PERK_CODE_ALPHABET[Math.floor(rand() * PERK_CODE_ALPHABET.length)];
  }
  return `ROOM-${suffix}`;
}

export function buildPassFields(
  paidAt: number,
  cfg: Pick<AppConfig, 'passRestyles' | 'passDays' | 'perkDiscountPct' | 'perkDays'>,
  code: string,
): { pass: LeadPass; perk: LeadPerk; looks: Look[] } {
  return {
    pass: { restylesTotal: cfg.passRestyles, restylesUsed: 0, expiresAt: paidAt + cfg.passDays * DAY_MS },
    perk: { code, discountPct: cfg.perkDiscountPct, validUntil: paidAt + cfg.perkDays * DAY_MS },
    looks: [],
  };
}
```

```ts
import { db } from '../admin';
import { generatePerkCode } from '../../../src/domain/pass';

const MAX_ATTEMPTS = 10;

/**
 * Draws perk codes until one isn't used by any lead. 32^4 ≈ 1M codes, so a
 * collision is rare; the retry exists for correctness, not throughput.
 */
export async function allocatePerkCode(rand?: () => number): Promise<string> {
  for (let attempt = 0; attempt < MAX_ATTEMPTS; attempt++) {
    const code = generatePerkCode(rand);
    const clash = await db.collection('leads').where('perk.code', '==', code).limit(1).get();
    if (clash.empty) return code;
  }
  throw new Error('Could not allocate a unique perk code');
}
```

```ts
import sharp from 'sharp';
import path from 'node:path';
import { readFileSync } from 'node:fs';

/** Below this width there's nothing meaningful to mark (and the mock 1x1 PNG must pass through). */
export const MIN_WATERMARK_WIDTH = 200;

// lib/functions/src/generation/ -> ../../../../assets ; src/generation/ -> ../../assets
function loadMark(): Buffer {
  const candidates = [
    path.join(__dirname, '..', '..', 'assets', 'watermark.png'),
    path.join(__dirname, '..', '..', '..', '..', 'assets', 'watermark.png'),
  ];
  for (const p of candidates) {
    try { return readFileSync(p); } catch { /* try next */ }
  }
  throw new Error('watermark.png not found');
}

let markBytes: Buffer | undefined;

/**
 * Composites the "Preview by Lyssasky" mark into the bottom-right corner at
 * ~28% of the image width. Throws on failure — the caller decides whether a
 * missing watermark is fatal (it isn't, see generateImage).
 */
export async function applyWatermark(bytes: Buffer): Promise<Buffer> {
  const meta = await sharp(bytes).metadata();
  const width = meta.width ?? 0;
  const height = meta.height ?? 0;
  if (width < MIN_WATERMARK_WIDTH) return bytes;

  markBytes ??= loadMark();
  const markWidth = Math.round(width * 0.28);
  const mark = await sharp(markBytes).resize({ width: markWidth }).png().toBuffer();
  const markHeight = (await sharp(mark).metadata()).height ?? 0;
  const margin = Math.round(width * 0.02);

  return sharp(bytes)
    .composite([{ input: mark, left: width - markWidth - margin, top: Math.max(0, height - markHeight - margin) }])
    .png()
    .toBuffer();
}
```

```ts
  if (!lead) return;

  // Hard requirement: runGeneration must NEVER throw (see onLeadPaid) — a
  // thrown error would strand a PAID lead at 'paid' with no admin signal.
  try {
    if (!lead.answers) throw new Error(`Lead ${leadId} is missing answers; cannot run generation`);
    const { outputPhotoPath, costEstimate } = await generateLook(leadId, lead, lead.answers, provider);

      looks: [...(lead.looks ?? []), look],
```

```ts
async function assertValidChoice(styleSlug: unknown, colorMood: unknown): Promise<void> {
  const style = typeof styleSlug === 'string' && styleSlug
    ? ((await db.collection('styles').doc(styleSlug).get()).data() as Style | undefined)
    : undefined;
  if (!style || !style.active) throw new HttpsError('invalid-argument', "That style isn't available");
  const config = await loadConfig();
  const moods = config.questionnaire.find((q) => q.id === 'colorMood')?.options ?? [];
  if (typeof colorMood !== 'string' || !moods.some((o) => o.value === colorMood)) {
    throw new HttpsError('invalid-argument', "That color mood isn't available");
  }
}

/** Reserves one restyle atomically. Returns the live lead snapshot it reserved against. */
async function reserveRestyle(leadId: string, uid: string, isAdmin: boolean): Promise<Lead> {
  const ref = db.collection('leads').doc(leadId);
  return db.runTransaction(async (tx) => {
    const lead = (await tx.get(ref)).data() as Lead | undefined;
    if (!lead) throw new HttpsError('not-found', 'Lead not found');
    if (!isAdmin) assertOwner(uid, lead);
    const now = Date.now();
    if (!lead.pass || isPassExpired(lead, now)) {
      throw new HttpsError('failed-precondition', 'Your Room Pass has ended');
    }
    if (lead.generatedImagePaths.length === 0) {
      throw new HttpsError('failed-precondition', 'Your first look is still on its way');
    }
    if (isRestyleInFlight(lead, now)) {
      throw new HttpsError('aborted', 'A look is already being generated');
    }
    if (restylesLeft(lead) <= 0) {
      throw new HttpsError('resource-exhausted', "You've used all your restyles");
    }
    tx.update(ref, { 'pass.restylesUsed': lead.pass.restylesUsed + 1, 'pass.inFlight': now, updatedAt: now });
    return lead;
  });
}

export async function restyleDoc(
  leadId: string,
  uid: string,
  input: { styleSlug: string; colorMood: string },
  opts?: { isAdmin?: boolean; provider?: GenerationProvider },
): Promise<{ imagePath: string; restylesLeft: number }> {
  await assertValidChoice(input?.styleSlug, input?.colorMood);
  const lead = await reserveRestyle(leadId, uid, opts?.isAdmin === true);
  const ref = db.collection('leads').doc(leadId);
  const answers = { ...lead.answers!, styleSlug: input.styleSlug, colorMood: input.colorMood };

  let result;
  try {
    result = await generateLook(leadId, lead, answers, opts?.provider);
  } catch {
    // Refund inside a transaction so a concurrent read never sees a
    // half-refunded pass. Status is deliberately left alone: only a failed
    // FIRST preview moves a lead to 'failed'.
    await db.runTransaction(async (tx) => {
      const live = (await tx.get(ref)).data() as Lead;
      tx.update(ref, {
        'pass.restylesUsed': Math.max(0, live.pass!.restylesUsed - 1),
        'pass.inFlight': FieldValue.delete(),
        updatedAt: Date.now(),
      });
    });
    throw new HttpsError('internal', "We couldn't create that look — your restyle wasn't used. Please try again.");
  }

  const now = Date.now();
  const look: Look = { imagePath: result.outputPhotoPath, styleSlug: input.styleSlug, colorMood: input.colorMood, createdAt: now };
  const updated = await db.runTransaction(async (tx) => {
    const live = (await tx.get(ref)).data() as Lead;
    const next = {
      generatedImagePaths: [...live.generatedImagePaths, result.outputPhotoPath],
      looks: [...(live.looks ?? []), look],
      costEstimateTotal: live.costEstimateTotal + result.costEstimate,
      'pass.inFlight': FieldValue.delete(),
      updatedAt: now,
    };
    tx.update(ref, next);
    return live;
  });
  return { imagePath: result.outputPhotoPath, restylesLeft: restylesLeft(updated) };
}

export const restyle = onCall({ timeoutSeconds: 120 }, async (req) => {
  if (!req.auth) throw new HttpsError('unauthenticated', 'Sign-in required');
  const { leadId, styleSlug, colorMood } = (req.data ?? {}) as Record<string, unknown>;
  if (typeof leadId !== 'string' || !leadId) throw new HttpsError('invalid-argument', 'leadId is required');
  return restyleDoc(leadId, req.auth.uid, { styleSlug: styleSlug as string, colorMood: colorMood as string }, {
    isAdmin: req.auth.token?.admin === true,
  });
});
```

```ts
  if (v === null || v === undefined) return '';
```

```ts
import { onSchedule } from 'firebase-functions/v2/scheduler';
import { db } from '../admin';
import { DAY_MS } from '../../../src/domain/pass';
import { sendEmailDoc, loadEmailLabels } from './sendEmail';
import { renderPassExpiringHtml, resultUrlFor } from './templates';
import type { Lead } from '../../../src/domain/types';

/** Claims the reminder transactionally so overlapping runs never double-send. */
async function claimReminder(leadId: string): Promise<Lead | null> {
  const ref = db.collection('leads').doc(leadId);
  return db.runTransaction(async (tx) => {
    const lead = (await tx.get(ref)).data() as Lead | undefined;
    if (!lead || lead.remindedAt || lead.booking || !lead.email) return null;
    tx.update(ref, { remindedAt: Date.now() });
    return lead;
  });
}

export async function sendPassReminders(now: number): Promise<number> {
  const snap = await db.collection('leads')
    .where('pass.expiresAt', '>', now)
    .where('pass.expiresAt', '<=', now + DAY_MS)
    .get();
  const candidates = snap.docs.filter((d) => {
    const l = d.data() as Lead;
    return !l.remindedAt && !l.booking && !!l.email;
  });
  if (candidates.length === 0) return 0;

  const labels = await loadEmailLabels();
  const appBaseUrl = process.env.APP_BASE_URL ?? 'http://localhost:5173';
  let sent = 0;
  for (const doc of candidates) {
    try {
      const lead = await claimReminder(doc.id);
      if (!lead) continue;
      await sendEmailDoc({
        to: lead.email!,
        subject: 'Your Room Pass ends tomorrow',
        html: renderPassExpiringHtml(lead, resultUrlFor(doc.id, lead, appBaseUrl), labels),
        kind: 'pass_expiring',
        leadId: doc.id,
      });
      sent += 1;
    } catch (err) {
      console.error(`sendPassReminders: lead ${doc.id} failed`, err);
    }
  }
  return sent;
}

export const passReminderSchedule = onSchedule('every 60 minutes', async () => {
  await sendPassReminders(Date.now());
});
```

```ts
import { onCall, HttpsError } from 'firebase-functions/v2/https';
import { db } from '../admin';
import { assertAdmin } from '../guards';
import type { Lead } from '../../../src/domain/types';

export async function adminMarkPerkRedeemedDoc(leadId: string): Promise<void> {
  const ref = db.collection('leads').doc(leadId);
  await db.runTransaction(async (tx) => {
    const lead = (await tx.get(ref)).data() as Lead | undefined;
    if (!lead) throw new HttpsError('not-found', 'Lead not found');
    if (!lead.perk) throw new HttpsError('failed-precondition', 'This lead has no perk');
    if (lead.perk.redeemedAt !== undefined) return;
    tx.update(ref, { 'perk.redeemedAt': Date.now(), updatedAt: Date.now() });
  });
}

export const adminMarkPerkRedeemed = onCall(async (req) => {
  assertAdmin(req.auth);
  const leadId = req.data?.leadId;
  if (typeof leadId !== 'string' || !leadId) throw new HttpsError('invalid-argument', 'leadId is required');
  await adminMarkPerkRedeemedDoc(leadId);
  return { ok: true };
});
```

```ts
import { db, storage } from '../admin';
import { DAY_MS } from '../../../src/domain/pass';
import { PLACEHOLDER_PNG_BASE64 } from '../generation/placeholder';
import type { Lead, Look } from '../../../src/domain/types';

const OWNER = 'seed-owner';
const MOODS = ['warm_cozy', 'light_airy', 'bold_dramatic', 'neutral_calm'];
const STYLES = ['scandinavian', 'japandi', 'modern-farmhouse', 'coastal', 'mid-century-modern', 'boho'];

interface Spec { id: string; used: number; expiresIn: number; status: Lead['status']; redeemed?: boolean; booked?: boolean }

const SPECS: Spec[] = [
  { id: 'sample-fresh', used: 0, expiresIn: 7 * DAY_MS, status: 'generated' },
  { id: 'sample-partial', used: 2, expiresIn: 4 * DAY_MS, status: 'rated' },
  { id: 'sample-exhausted', used: 5, expiresIn: 2 * DAY_MS, status: 'rated' },
  { id: 'sample-expired', used: 1, expiresIn: -DAY_MS, status: 'generated' },
  { id: 'sample-booked-redeemed', used: 3, expiresIn: 3 * DAY_MS, status: 'booked', redeemed: true, booked: true },
];

/** Emulator-only sample data so the admin and result pages can be eyeballed in every pass state. */
export async function seedSampleLeads(now: number): Promise<string[]> {
  const png = Buffer.from(PLACEHOLDER_PNG_BASE64, 'base64');
  const bucket = storage.bucket();
  for (const [i, spec] of SPECS.entries()) {
    const originalPhotoPath = `leads/${OWNER}/${spec.id}/original.png`;
    await bucket.file(originalPhotoPath).save(png, { contentType: 'image/png' });
    const looks: Look[] = [];
    for (let n = 0; n <= spec.used; n++) {
      const imagePath = `leads/${OWNER}/generated/${spec.id}-${n}.png`;
      await bucket.file(imagePath).save(png, { contentType: 'image/png' });
      looks.push({ imagePath, styleSlug: STYLES[n % STYLES.length], colorMood: MOODS[n % MOODS.length], createdAt: now - (spec.used - n) * 60_000 });
    }
    const paidAt = now + spec.expiresIn - 7 * DAY_MS;
    const lead: Lead = {
      id: spec.id, ownerUid: OWNER, leadToken: `token-${spec.id}`, email: `${spec.id}@example.com`,
      status: spec.status,
      answers: { roomType: 'living_room', styleSlug: looks[0].styleSlug, colorMood: looks[0].colorMood, budget: '1k_5k', timeline: 'within_3_months' },
      originalPhotoPath,
      generatedImagePaths: looks.map((l) => l.imagePath),
      looks,
      paymentId: `mock_${spec.id}`,
      pass: { restylesTotal: 5, restylesUsed: spec.used, expiresAt: now + spec.expiresIn },
      perk: {
        code: `ROOM-SMP${'ABCDE'[i]}`, discountPct: 10, validUntil: paidAt + 30 * DAY_MS,
        ...(spec.redeemed ? { redeemedAt: now - DAY_MS } : {}),
      },
      ...(spec.booked ? { booking: { name: 'Sample Customer', interest: 'virtual_styling' as const }, bookingNotifiedAt: now } : {}),
      ...(spec.status !== 'generated' ? { rating: 4, feedback: 'Love it, maybe warmer lighting' } : {}),
      costEstimateTotal: 0,
      timestamps: { captured: paidAt - 60_000, paid: paidAt, generated: paidAt + 30_000 },
      createdAt: paidAt - 60_000, updatedAt: now,
    };
    await db.collection('leads').doc(spec.id).set(lead);
  }
  return SPECS.map((s) => s.id);
}
```
